A clean, minimalist, no-login-required Todo List web app. No installations, no sign-ups — just open and start organizing your tasks.

All your data is stored securely in your browser's local storage, so your todos are always private and always available.

Built with **Vue 2.x** and **Sass**, using base64 assets to keep the project lightweight and dependency-free.

---

## Features

- ✅ Add, edit, and delete tasks effortlessly
- ✅ Mark tasks as complete or incomplete
- ✅ Drag and drop to reorder tasks *(PC only)*
- ✅ Double-click to edit the slogan or any task
- ✅ Quick actions available in the right sidebar
- ✅ Mark all tasks as done in one click
- ✅ Export your todos as a file
- ✅ Import todos from a `.txt` or `.json` file (appends to current list)
- 🔒 All data stored locally in your browser — no server, no account needed

---

## Getting Started

No installation required. Just download and open `index.html` in your browser.

```bash
git clone https://github.com/Rohithjava777/to-do-list-rohithside.git
cd to-do-list-rohithside
# Open index.html in your browser
```

---

## Usage Tips 💡

- Press **Enter** to quickly submit a new task or save edits
- **Drag** tasks up and down to reorder them *(PC only)*
- **Double-click** any task or the slogan text to edit it inline
- Use the **right sidebar** for quick batch actions (finish all, clear completed, etc.)
- Use **Export data** to back up your todos
- Use **Import (txt/json)** to restore or add todos from a file
